# Desktop Pet 0.4.2

## English

- Switch between Quick Input and Full Chat without losing unsent text. Closing and reopening a chat window also restores its draft.
- Drafts are separate for each character and stay only in memory. Quitting clears them, even with saved history enabled. Unsent drafts are not sent to a model service.
- Retry a failed or stopped reply directly from Quick Input. Failed sends restore the text without replacing a newer draft; retries only run when requested.
- Quick Input now supports multiple lines. Enter sends, Shift+Enter inserts a line break, and IME confirmation does not send a message.
- Streaming updates keep existing message bubbles and text selections intact. Reply completion no longer pulls focus away from the control being used. Use Latest reply to return to the bottom.
- Improved compact chat layouts, character names, and space for simultaneous error and voice controls.
- Reject submissions from an outdated character or conversation before contacting the model service.

Includes the response-size limits, TTS URL restrictions, and credential redaction from 0.4.1. Existing characters, settings, and optional history remain compatible. Voice and experimental affection remain off by default. This release does not include Live2D.

## 简体中文

- 快速输入与完整聊天共享未发送的文字，切换模式或关闭窗口后重新打开都能接着写。
- 草稿按角色分开，仅暂存在内存。退出应用后清除，即使开启聊天记录保存也不会保存草稿；未发送的草稿不会交给模型服务。
- 小窗可以直接重试失败或已停止的回复。发送失败会恢复文字，不覆盖之后输入的新草稿，也不会自动重试。
- 快速输入支持多行，Enter 发送、Shift+Enter 换行，输入法确认不会误发送。
- 流式回复保留已有气泡与文字选区，回复结束不再抢走焦点。可通过“最新回复”回到底部。
- 改善紧凑聊天窗口、角色称呼，以及错误提示与语音控件同时出现时的布局。
- 旧角色或旧会话窗口的过时请求会在调用模型之前被拦截。

保留 0.4.1 的响应大小限制、TTS 地址检查和密钥脱敏。现有角色、设置及可选保存的记录保持兼容。朗读和实验性好感度仍默认关闭，本版不包含 Live2D。

## 日本語

- クイック入力とチャット画面で未送信の文章を共有し、ウィンドウを開き直しても入力を続けられます。
- 下書きはキャラクター別にメモリ上だけで保持し、履歴保存の設定に関係なくアプリ終了時に消去します。未送信の文章をモデルサービスに渡すことはありません。
- 失敗・停止した返信をクイック入力から再試行できます。失敗時は新しい下書きを上書きせずに文章を戻します。自動再試行はしません。
- クイック入力で改行に対応。Enter で送信、Shift+Enter で改行し、IME の確定では送信しません。
- 逐次返信中も既存の吹き出しと文字選択を保持し、返信完了時にフォーカスを奪いません。「最新の返信」で末尾へ戻れます。
- 小さいチャット画面、キャラクター名、エラーと音声操作の同時表示を改善しました。
- 古いキャラクター・会話状態からの送信を、モデルへの接続前に拒否します。

0.4.1 の応答サイズ制限、TTS URL 検証、キーの非表示を維持しています。既存のキャラクター・設定・保存済み履歴と互換性があります。音声と実験的な好感度は引き続き初期設定ではオフです。Live2D は含まれません。
